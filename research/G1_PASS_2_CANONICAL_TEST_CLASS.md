# G1 Pass 2 — Canonical Test Class for Endogenous Maintenance

**Role:** Main Research
**Gate:** G1 — Mathematical Definition
**Status:** Controller-authorized research artifact
**Scope:** narrow open stochastic chemical reaction network / reaction-compartment class
**Null programme:** \`H_0 = known physics/chemistry\`. No \`Phi\`, G2 bound, or universal organization scalar is introduced.

## 1. Decision

This pass defines the narrowest useful **canonical test class** found so far for auditing the provisional Endogenous Maintenance Certificate (EMC): a finite-species continuous-time Markov jump reaction network with an explicit system/environment species partition, typed exchange/control/repair channels, identifiable reaction counts, predeclared viability observables, and provenance-preserving observation maps.

The test class is canonical as a **test class**, not as the universal MOB-LIFE admissible-system class. The EMC remains provisional.

## 2. Canonical test class

### 2.1 Species and state

**[DEF] Canonical test-class species partition.** Let
\[
\mathsf S=\mathsf S_{\rm int}\sqcup\mathsf S_{\rm bnd}\sqcup\mathsf S_{\rm env}\sqcup\mathsf S_{\rm ctrl}.
\]
Internal and boundary species form the system-side count state
\[
X_t=(N_i(t))_{i\in\mathsf S_{\rm int}\cup\mathsf S_{\rm bnd}}\in\mathbb N_0^d.
\]
Environmental/controller variables may enter propensities as declared exogenous protocols or be included in an enlarged Markov state when dynamically modelled.

**[DEF] Boundary.** For this test class, \(\mathcal B\) is the declared partition separating internal/boundary species from environment/controller degrees of freedom, together with the list of cross-boundary channels. Changing that partition is a boundary refinement and requires a new EMC audit.

### 2.2 Reactions and stochastic dynamics

Let \(\mathsf R=\{1,\dots,m\}\). Each channel \(r\) has reactant/product complexes \(y_r,y'_r\), stoichiometric jump \(\nu_r=y'_r-y_r\in\mathbb Z^d\), and propensity \(a_r(x,t)\ge0\).

**[EST]** Under standard existence/nonexplosion assumptions, the stochastic CRN is a continuous-time Markov chain with generator
\[
(\mathcal L_t f)(x)=\sum_{r\in\mathsf R}a_r(x,t)[f(x+\nu_r)-f(x)].
\]
Equivalently, with independent unit-rate Poisson processes \(Y_r\),
\[
X_t=X_0+\sum_rY_r\!\left(\int_0^t a_r(X_s,s)\,ds\right)\nu_r.
\]
This reaction-count representation makes channel currents identifiable (S023).

**[DEF] Path law.** \(P^{\mathcal M}_{0:T}\) is the law on cadlag paths and typed reaction-event records generated by model \(\mathcal M\) over predeclared horizon \(T\).

### 2.3 Typed channels

Every channel receives exactly one provenance class before EMC evaluation:

- \(\mathsf R_{\rm int}\): internal process-mediated transition; state-conditioned mediating degrees needed for the transition are system-side, apart from raw reservoir reactants/free-energy supply.
- \(\mathsf R_{\rm sup}\): supply/removal exchange; transfers raw matter/free-energy carriers without an external state-conditioned restorative policy.
- \(\mathsf R_{\rm forc}\): external open-loop forcing; externally scheduled modulation independent of online system-state measurement.
- \(\mathsf R_{\rm ctrl}\): external feedback/control; action depends on a system measurement/signal and the policy is physically realized outside \(\mathcal B\).
- \(\mathsf R_{\rm rep}\): external repair/replacement; an externally mediated channel directly restores/replaces a declared maintained or boundary component.

**[DEF] Non-circular typing rule.** Type is determined from physical provenance and conditional dependence, without reference to whether EMC will pass. A nutrient inflow does not become internal because it aids viability; a feedback pump does not become supply merely because its actuator is simple.

If an external controller is moved inside a refined boundary, the affected channel may be retyped only after the enlarged controller state, supply, degradation and repair dependencies are explicitly represented.

### 2.4 Viability and loss

Before intervention testing choose a measurable viability observable \(V:X\to\mathbb R^q\), admissible region \(K\), maintained variables \(Y=(Y_1,\dots,Y_k)\), and a nonempty physically specified set \(\mathsf R_{\rm loss}\) of degradation/leakage/dilution transitions.

**[DEF] Viability event.**
\[
\mathcal V_T=\{V(X_t)\in K\ \forall t\in[0,T]\}.
\]
Neither \(V,K,Y\), nor loss channels may be selected by optimizing the EMC verdict on the same comparison.

## 3. Intervention semantics

For \(A\subseteq\mathsf R\), define reaction removal \(\mathcal M^{-A}\) by setting \(a_r=0\) for \(r\in A\), retaining the same initial law, external protocols and structural forms of all nonremoved propensities.

**[ASM] Modular intervention assumption.** Removal is causally interpretable only if the remaining model is well-defined and the mechanism can be disabled without silently changing other mechanism laws. Otherwise simple reaction removal is not an admissible causal test.

## 4. RCC on the test class

For maintained component \(Y_i\), predeclare internal restoration channels \(\mathsf R^{i}_{\rm rest}\subseteq\mathsf R_{\rm int}\). Define their pathwise restoration count/current from typed reaction counts and positive increments of \(Y_i\).

**[CAND] RCC.** Component \(i\) passes over \([0,T]\) if: a loss challenge is active; internal restoration current is nonzero; removing \(\mathsf R^{i}_{\rm rest}\) materially worsens a predeclared viability/return statistic; and external control/repair does not supply the certified restoration.

A preferred comparison is
\[
\Delta_i(T)=P^{\mathcal M}(\mathcal V_T)-P^{\mathcal M^{-\mathsf R^{i}_{\rm rest}}}(\mathcal V_T),
\]
with threshold \(\delta_i>0\) predeclared. RCC remains provisional.

## 5. CRDC on the test class

Define edge \(j\to i\) only if predeclared internal reactions mechanistically mediated by \(Y_j\) contribute to restoration/production of \(Y_i\), and disabling that mediation materially reduces the declared restoration/viability statistic under the modular intervention assumption.

**[CAND]** \(G_M\) is therefore intervention-backed, not correlation-inferred.

**[CAND] CRDC.** A maintained subset passes if every node lies in a directed renewal-support cycle mediated internally, including any boundary component required for those dependencies. Supply and external controller/repair nodes cannot close the cycle.

## 6. EMC on the test class

**[CAND] EMC** passes when: loss challenge is nontrivial; required components pass RCC; their intervention-backed graph passes CRDC; restorative mediation is internal; external supply provides only admissible raw matter/free energy rather than essential feedback/repair; \(T\) is declared relative to turnover scales; and the observation map preserves provenance/dependency information needed to audit these statements.

EMC is boundary-, horizon-, component- and representation-relative. It is not a definition of life.

## 7. Explicit model family

### M0 — passive/no-renewal persistence
A stable component \(B\) persists with no restoration, or loss is negligible over \(T\). **Verdict:** RCC fails if loss is exposed; if \(T\) exposes no declared loss, EMC is not identifiable rather than passed.

### M1 — externally maintained persistence
\[
B\to\varnothing,\qquad \varnothing\xrightarrow{u(B)}B,\quad u(B)=k_c(b_*-B)_+.
\]
The second channel is external feedback/control. **Verdict:** viability may be high, but endogenous RCC/EMC fails provenance. Retyping it as supply is prohibited.

### M2 — open autocatalytic chemistry without maintained compartment
With chemostatted food \(F\),
\[
2A+F\to3A,\qquad A\to\varnothing.
\]
Food exchange is supply/removal. **Verdict:** \(A\) may pass an RCC-like catalytic restoration test, but no maintained boundary node/compartmental CRDC exists. Autocatalysis alone is insufficient.

### M3 — reaction-compartment endogenous-maintenance candidate
Use catalyst \(A\), membrane precursor \(L\), boundary units \(B\), chemostatted food and waste export:
\[
2A+F\to3A,\quad A+F\to A+L,\quad L\to B,\quad A\to\varnothing,\quad B\to\varnothing.
\]
Boundary abundance \(B\) must mechanistically affect retention/transport (for example catalyst leakage or food uptake), so \(A\) supports \(B\) renewal and \(B\) supports conditions for \(A\) renewal. Predeclare \(Y=(A,B)\) and \(K=\{A\ge a_{\min},B\ge b_{\min}\}\).

Removing autocatalysis tests \(A\) renewal; removing \(A\)-mediated lipid production tests \(B\) renewal; disabling the \(B\)-dependent retention/transport mediation tests the \(B\to A\) edge. Passing requires positive renewal currents and predeclared intervention effects. This is a test construction, not evidence about real protocells. Established models show autocatalytic/reaction chemistry can be coupled to maintained compartments (S024–S025).

### M4 — internally self-repairing engineered analogue
Represent internal controller \(C\), functional component \(Y\), repair precursor \(R\) and fuel \(F\). Internal mechanisms restore \(Y\) and maintain \(C\); raw \(R,F\) arrive as nonfeedback supply. **Verdict:** if RCC/CRDC pass, EMC passes. This is intentional: EMC certifies endogenous maintenance, not life.

## 8. Boundary-refinement test

Start from M1 with controller outside \(\mathcal B_0\): EMC fails endogenous provenance. Refine to \(\mathcal B_1\) by including controller/actuator state.

Merely moving a label is insufficient. The enlarged model must expose controller dynamics, energy/material supply, degradation/failure, repair/replacement and actuator coupling. If the controller is externally repaired, the renewal chain terminates in external repair and CRDC still fails. If it is internally renewed in an intervention-backed cycle, EMC may legitimately change to pass.

**Result:** EMC is not boundary-invariant. Its verdict is meaningful only with the boundary and provenance declared. Boundary refinement is scientifically substantive.

## 9. Coarse-graining test

For M3 compare:
- \(C_{\rm fine}\): retains \(A,B\), typed reaction counts, boundary labels and provenance;
- \(C_{\rm count}\): aggregates microchannels but retains provenance and maintained-variable increments;
- \(C_{\rm state}\): retains sampled \(A(t),B(t)\) only.

RCC/CRDC can survive \(C_{\rm count}\) only if no aggregate mixes provenance and intervention sets descend unambiguously. Under \(C_{\rm state}\), internal renewal and hidden external feedback can generate indistinguishable state histories; reaction-removal semantics and dependency provenance are not identifiable.

**[DEF] EMC-admissible observation map (test class).** It preserves: maintained variables/viability event; loss/restoration event identity or sufficient current statistics; channel provenance; intervention mapping for dependency edges; and boundary membership of mediating degrees of freedom.

## 10. Canonicalization decision

**Promote:** restricted stochastic reaction-compartment test class; species/boundary partition and channel provenance; predeclaration rule; modular reaction-removal semantics; EMC-admissible observation-map criterion.

**Do not promote:** EMC/RCC/CRDC as universal definitions; universal admissible system class; boundary invariance; any scalar organization quantity.

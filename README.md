# MOB-LIFE

**Derivation of a Multiscale Organization Bound for the Emergence of Life**

This repository is the canonical, durable research record for MOB-LIFE. The programme asks how far known physics, chemistry, and mathematics can constrain the emergence of increasingly self-maintaining, heritable, and evolvable organization.

## Current scope

The repository is being established under explicit research gates. No gate is advanced by elapsed time or number of research passes; advancement requires its substantive prerequisites to be satisfied and recorded in `STATUS.md`.

The programme begins from the null hypothesis

```text
H0 = known physics/chemistry (with established mathematics)
```

No unknown organizing field is assumed. A candidate `Phi` extension is admissible only after the known-physics programme is sufficiently developed and a precise residual obstruction survives.

## Gate sequence

G0 Repository Foundation -> G1 Mathematical Definition -> G2 Candidate Organization Bound -> G3 Regular/Special Case -> G4 Exhaustive Case Decomposition -> G5 Known-Physics Bound -> G6 Residual Obstruction -> G7 Candidate Phi Extension -> G8 Mathematical Derivation -> G9 Computational Verification -> G10 Experimental Implications.

See `MASTER_INSTRUCTIONS.md` for research discipline and `STATUS.md` for the operational state.

## Repository map

- `research/` — scoped research passes and architecture notes.
- `mathematics/` — definitions, notation, case decompositions, and eventual derivations.
- `sources/` — source ledger and provenance conventions.
- `computation/` — future computational verification; inactive until its gate.
- `reviews/` — independent reviews and repository audits.
- `negative-results/` — scientifically informative failures, exclusions, and dead ends.

## Reproducibility rule

Chat discussion is not repository evidence. External material becomes project evidence only when migrated with appropriate provenance and epistemic classification.

# G1 Pass 1 — Counterexamples and Definition Failures

These are retained because they constrain future definitions. They are not claims that the listed components are useless; they show that each is insufficient **alone**.

| ID | Candidate weakened/rejected as sufficient | Counterexample | Failure |
|---|---|---|---|
| NR-G1-01 | high spatial correlation/order | equilibrium crystal | passive equilibrium order can be extremely strong |
| NR-G1-02 | high entropy / information content | random noise | entropy can be maximal while predictive/functional structure is absent |
| NR-G1-03 | persistence/memory | frozen disorder | static persistence requires no active renewal |
| NR-G1-04 | multiscale structure + dissipation | turbulence | rich scale structure and flux do not imply closure/self-maintenance |
| NR-G1-05 | coherent nonequilibrium pattern | convection | driven matter self-organizes into stable patterns without life |
| NR-G1-06 | feedback/control/network complexity | externally controlled machine | organization-like behavior can be maintained by external controller/resources |
| NR-G1-07 | temporal persistence/predictability | simple oscillator | periodicity gives strong prediction without self-maintaining organization |
| NR-G1-08 | mutual information/correlation | passive coupled system | dependence can arise from equilibrium coupling/common causes |
| NR-G1-09 | stored information | static archive | large structured information can be inert |
| NR-G1-10 | autocatalysis/RAF status | simple RAF | food-generated collective catalysis need not supply boundary, heredity or autonomous maintenance |
| NR-G1-11 | topology | passive patterned/material system | nontrivial topology is not specific to organization/life |
| NR-G1-12 | coarse-grained memory as intrinsic memory | hidden-variable reduction | eliminating variables can generate effective memory in reduced dynamics |

## Consequence

**[CAND]** Future organization definitions must be conjunctive or profile-based enough to distinguish statistical structure, persistence, active endogenous maintenance, open-system exchange, catalytic/constraint relations, and boundary dependence. No arbitrary weighted scalar is licensed by these failures.

**[OPEN]** The next attack target is a path-level criterion for endogenous maintenance versus passive persistence or externally imposed maintenance.
